# A bounded beta trial / 小范围公开试用

Choose one non-sensitive synthetic project and one convention. Install the pinned beta, restart the host, inspect memory_status, and ask to remember the convention. Keep the actual write outcome. Query it in a fresh conversation. Then change the convention and check the current value and history.

一次只改变一个因素：项目归属、措辞、条件或修订关系。记录失败和未完成，不用手工修改数据库补齐结果。请勿上传真实会话或个人记忆，也不要求付费模型批量运行。

Record: plugin/DSH/Node/OS versions; input; actual write status; fresh-chat question and answer; source/scope difference; error code. Use the issue templates for a minimal reproduction.

This is an invitation and protocol, not an executed evaluation. No reward, response time, reimbursement or stable-release commitment is promised.
