# SoloPup Memory: source-linked text memory for DSH

状态：可复用文案，尚未投放第三方平台。 / Copy prepared; not posted to third-party platforms.

SoloPup Memory is an MIT-licensed text-memory plugin for DeepSeek Harness. It separates global preferences from project decisions and retains source citations, conditions and revision history. Version 0.21.0-beta.2 is a public beta. Retrieval is lexical, and model-assisted review can miss or misinterpret information. Try one synthetic convention, inspect the real write result, and query it in a fresh conversation. Reproducible failures are welcome.
