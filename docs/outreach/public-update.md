I maintain SoloPup Memory, an MIT-licensed text-memory plugin for DeepSeek Harness. The stable 0.26.0 release brings a short list of applicable, source-linked decisions into a resumed workspace. After a file edit, supported hosts can prompt one final review of the actual handoff. The earlier beta evaluation includes scores by comparison group and the checks each group missed.
