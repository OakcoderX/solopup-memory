# 用 DSH 续写，把已经确认的改动带到交付

我是 SoloPup Memory 的维护者。它是一款给 DeepSeek Harness（DSH）用的开源文字记忆插件。文字记忆稳定版 0.26.0 已发布。 [安装稳定版](../guides/quickstart.md)

三版稿都还在，你最后确认「第七章用第二版，结尾照旧，改完附一份修改说明」。换回同一个工作区继续时，0.26 会把与本轮相关的现行约定列出来，保留出处和例外。支持的 DSH 宿主上，助手编辑文件后准备收尾时，可以再核对一次成果和约定。

用两份虚构的 Markdown 稿试一次。先记下决定，再开新会话请助手实际改稿。打开成稿和修改说明，核对选用的正文、保留的结尾和附上的文件。评测记录列出了对照条件、分数、通过项和遗漏项。 [试用步骤](tester-invite.md) · [历史评测结果](../runs/2026-11-18-memory-delivery.md)

欢迎下载源码或 Fork，在你的 DSH 工作流里复跑。带上版本、运行步骤和虚构样例，就能一起查清记住的是什么、最后到底交付了什么。 [下载版本源码](https://github.com/OakcoderX/solopup-memory/releases/tag/v0.26.0) · [Fork 源码](https://github.com/OakcoderX/solopup-memory/fork) · [反馈入口](../feedback.md)
