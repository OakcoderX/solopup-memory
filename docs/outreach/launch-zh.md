# 用 DSH 接着写上一回的稿子

我是 SoloPup Memory 的维护者。它是一款给 DeepSeek Harness（DSH）用的开源文字记忆插件。

长篇项目里，一句话就能决定后续怎么写。比如三版稿都留着，你确认「第七章用第二版，结尾照旧」。下次开新会话，助手需要记住采用了哪一稿、只改了哪一处，还要能核对你当时怎么说。SoloPup 会给已确认的文字记忆保留出处、项目归属和修订历史。

可以用两份虚构的 Markdown 稿试一次。明确记下一条带例外的决定，打开新会话问「这个章节该用哪版，哪里照旧，依据是什么？」如果答错，欢迎带上运行版本、步骤和非敏感示例来反馈。
