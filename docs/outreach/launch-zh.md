# SoloPup Memory：让 DSH 留下有来源的文字记忆

状态：可复用文案，尚未投放第三方平台。 / Copy prepared; not posted to third-party platforms.

做长期项目时，难的往往不只是记住一句话，还包括分清“个人偏好”和“项目决定”，以及改主意后不再沿用旧规则。SoloPup Memory 是面向 DeepSeek Harness 的开源文字记忆插件，保留原话引用、项目归属和修订历史。当前为 0.22.0-beta.3 公开测试版；已有有限真实宿主验证，仍可能漏记或误解。欢迎用虚构的项目约定测试“明确记住 → 新会话找回”，并反馈失败。
