# SoloPup 0.24 做梦复核验收记录

本轮验证 DSH 闲置后复核项目记忆、回查原话、生成建议、用户采纳和后续会话使用。测试使用虚构项目与隔离的 DSH profile。普通模式可单独运行。Super Agent 为 macOS 实验模式，验证组合为 DSH `0.2.2-rc.1`、Node `24.21.0`、原型 `8c32a9dc5d72c033816c6a8110b37f40cf94fba4`。 [开启方式](../dream-review.md)

真实模型的最终验收归档为 `0.24.0-beta.1`，SHA-256 `f8b246b3d79ee6d3e9f4427043bb97f9d6d11d0ff2d8aea2d2e66b5b7ee7d36a`。解包测试 1077 通过、0 失败、6 个外部可选探针跳过。GitHub 检查发现源码中的新回读测试漏接了发布清单，因此该标签在 npm 发布前停止。

`0.24.0-beta.2` 修复测试入口与打包清单。本地归档 SHA-256 `44bc35c0ff8c5ad7e41f69ff1484d6972454b01fb6f05906b9634fa5f74e812a`。GitHub 流水线归档 SHA-256 `869c0d879a738056c5cd8557ed7e54e69950b781124d1ba2301a12942211499f`，两份归档解压后的 tar 逐字节一致。与 beta.1 相比，产品运行模块除版本号外字节一致，新增内容是回读实验脚本和对应测试。beta.2 源码和解包测试均为 1080 通过、0 失败、6 个外部可选探针跳过。双模式切换、历史报告和升级回退均通过可控模型复验。真实模型证据标注原测试归档。 [首次发布检查](https://github.com/OakcoderX/solopup-memory/actions/runs/43323418302) · [beta.2 发布检查](https://github.com/OakcoderX/solopup-memory/actions/runs/43325331316)

| 实验 | 结果 |
| --- | --- |
| 真实宿主和可控模型 | DSH 关闭做梦时零派发。开启后等待真实前台轮次结束，再按闲置门槛启动。后台只提交一份报告，原话可在当前项目打开，正式记忆指纹一致。 |
| 双向切换与隔离 | 同一安装归档执行普通 → Super Agent → 普通。两次切换等待在途工作结束，三份报告各提交一次。Worker 在默认拒绝的 macOS 文件与网络权限下运行，模型连接由宿主负责。移除伴随服务后，新切换被拒绝。 |
| 升级回退 | 官方插件管理器从 `0.23.0-beta.2` 升级，再回装旧版。受检项目记忆、来源、撤回状态、报告和待办保留。 |
| 真实复核 | 相同证据、DeepSeek Flash、思考关闭、无工具。十例的匿名 AI 评分为普通 9/10、Super Agent 10/10，零关键错误。完整十例使用计量修复前归档，提示和证据与最终归档相同。最终归档重新跑两种模式的两道留出题，各 2/2、零关键错误，两次均完整计量 666 输入 token。 |
| 只生成报告与采纳 | 不带历史原话的三个独立 DSH 会话中，旧记忆和只生成报告均回答中文，正式采纳后回答英文。报告组使用完整句子，严格的一词格式校验未通过。两个未采纳组的注入内容指纹一致。 |
| 带原话的新会话 | 同一五题在四组中共运行 20 次。仅原话、旧记忆加原话、修订加原话、只生成报告加原话分别为 5/5、4/5、5/5、5/5。指定改语言题的新旧组都根据原话答对，预设的改善判据未通过。旧记忆组在另一题有一次对未知模板的错误推断，同注入内容的报告组答对。 |

早期真实试验暴露了漏引原话、证据不足时给出肯定建议，以及把旧约定失效当成已有替代规则的问题。调整提示的判断顺序后重跑。试验还发现宿主单列缓存输入，最终归档将未缓存、缓存读和缓存写都计入预算。全部阶段共 40 次真实模型调用、8979 输出 token。对早期未计入缓存的输入作保守估算后，完整输入上界为 115851 token。

这些样本支持公开测试版的流程与指定兼容组合。样本规模不足以比较两种执行方式的优劣，也没有测出带完整原话时采纳修订的额外收益。正式记忆更新仍由用户通过现有写入流程确认。

可复验入口见 [`scripts/soak-dream.mjs`](../../scripts/soak-dream.mjs)、[冻结案例及评分表](../../eval/dream-review-cases.mjs)、[真实宿主试验驱动](../../eval/dream-review-dsh-transport.mjs)和[下一次会话对照](../../eval/dream-return-path-trial.mjs)。
