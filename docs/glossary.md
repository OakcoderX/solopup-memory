# Memory terms / 记忆术语

| Term | 含义 |
|---|---|
| Source / 来源 | 原话与身份；解释应能回到其证据 |
| Candidate / 候选 | 待判断的提议，不等于有效记忆 |
| Effective memory / 有效记忆 | 通过检查后可供后续检索的记录 |
| Claim / 本人主张 | 本人报告、尚未独立核实的内容 |
| Scope / 归属 | 全局或指定项目的适用范围 |
| Conditions / 条件 | 必须全部满足的适用条件 |
| Exception / 例外 | 任一命中即可排除默认规则的情形 |
| Revision / 修订 | 当前值与旧值之间可追踪的变更关系 |
| Withdrawal / 撤回 | 受管追踪来源与投影的撤回，不等于抹除所有副本 |
| Fresh-chat recall / 新会话召回 | 无继承聊天历史时实际找回，而非复述当前上下文 |
