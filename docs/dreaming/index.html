设计来源

为什么挑在闲置时复核？

做当前任务时先保留记录，空出时间再回头整理。这个分工借鉴了记忆研究，也出现在 Anthropic 对代理记忆的讨论里。 [The components of agent memory]

大脑在睡眠中重现活动

  1. 清醒时学习或探索。
  2. 慢波睡眠中，部分相关神经活动再次出现。
  3. 实验发现，特定线索可帮助一些记忆在醒来后保留。

大鼠实验记录到海马活动的重现。人类实验用与学习有关的气味作提示，观察到特定任务的记忆保留有所改善。研究测的是神经活动和任务表现，主观梦境是另一种现象。 [Wilson 与 McNaughton，1994] [Rasch 等，2007]

SoloPup 在闲置时核对记录

  1. 会话留下原话，已采纳的约定进入项目记忆。
  2. DSH 闲置后，模型按项目核对有限的原话。
  3. 你审阅建议并确认写入，新会话才获得修订值。

Anthropic 的 Dreams API 可读取既有记忆库及会话并生成整理后的新库。SoloPup 0.24 先生成一份可回查的报告，把正式写入留给你。 [Claude Dreams 文档]

普通模式由 DSH 执行复核。配置 Super Agent 后，你可改由隔离 Worker 处理同一批证据。宿主持有模型连接，Worker 只获得本次任务输入和所需运行文件。SoloPup 管理项目范围、队列、预算和报告。功能默认关闭，开启后默认等前台连续闲置 20 分钟。
