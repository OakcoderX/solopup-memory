# 第一次养大肥鱼：先让它回你一句，再看看它记不记得

**适合谁：** 刚看到别人养大肥鱼，自己还没打开过 DeepSeek Harness（DSH）。这篇先做一条只在你电脑上聊天的「文字鱼」。不做桌宠，不接 QQ、B 站或直播，也不用拿真实聊天来训练它。

## 0｜先别装一堆插件

养鱼可以拆成三件事：**人设**决定它怎么说话，**桌宠**让你看见它，**记忆**决定换个窗口后还有哪些约定。先做第一件。之后碰到哪个问题，再装解决那个问题的插件。

打开 [DSH 官方说明](https://github.com/deepseek-ai/deepseek-harness#run-from-npm)。它给的 Web 启动方式是：安装 Node.js 后，在终端运行下面一行。第一次装的人，先在同一个终端用 `node -v` 确认系统找得到 Node。

```sh
npx @deepseek-ai/dsh web
```

启动后在**这台电脑**的浏览器里打开终端显示的地址，默认是 `http://127.0.0.1:3080`。按官方界面选择你已有权限的模型；如果它要求密钥，只在官方设置中填，不要贴进聊天。模型可能计费。再点 **Choose workspace（选择工作区）**，选一个空白测试文件夹；没选工作区，输入框可能不可用。接着发第 1 步的第一句话，看是否真的收到回复。页面没开就先看终端报错；页面开了却没回话，就先查模型配置，暂时不用装插件。

## 1｜给它一句像样的人设

新建一段聊天。你可以复制这段，也可以把「小鱼」换成自己的名字：

> 你叫小鱼，是我的片单搭子。说话像朋友，简短一点，别每句都卖萌。我说的片子你没看过，就直接说不知道。先用一句话跟我打个招呼。

看到它回了一句，就算第一步完成。**粘贴在人设提示里的内容，别默认新会话也能看见。** 这个练习不需要装任何桌宠或社交插件。

## 2｜不装新东西，先测你手上的鱼

建议用两个普通的空白文件夹当工作区 A 和 B，别用已经连起来共享记忆的 Git 工作树。下面只用虚构信息。

1. 在工作区 A 说：「先定一条：只在这个工作区，片单优先选长片。」然后说：「改一下：这条旧规矩作废，只收 **10 分钟以内（含 10 分钟）**的片子。」
2. 在同一聊天里给它三部虚构片：《窗台的雨》8 分钟、《鱼缸里的月亮》10 分钟、《末班车》26 分钟。让它按这个工作区的规则交一张片单。前两部入选，26 分钟的那部不入选。这里验的是**交回来的东西**，不是它有没有说“我记住了”。
3. 如果想加一个对照，先从列表重新打开 A 里刚用过的同一条聊天，问「现行规则是什么？」；能答对只说明这条旧聊天内看得到上下文。接着做真正的新会话测试：回到工作区 A，**新建会话，不复制旧聊天，也别连同提示词把规则贴过去。** 给它同一组片名和时长，只问：「按我们这个工作区的现行规则交一张片单。你按的是哪句原话？查不到就写查不到。」答对两部但拿不出真实出处，记成「片单对，来源未证实」。答不上来也不一定是故障：可能是你现在的设置并没有跨会话记忆。
4. 在空白工作区 B 只问：「这个工作区有固定的片单时长要求吗？」它不应把 A 的十分钟规定当成 B 的既定规则。**别让它在 B 猜片单**，否则刚好挑了短片也不能证明它串了规则。

如果你现在的方案已经能做到，就不必再装一个记忆插件。

## 3｜确实需要跨会话记忆，再试 SoloPup Memory

这一步可跳过。SoloPup Memory 是我们维护的开源插件，只试 **DSH 原生文字会话**里的约定；它不会接管桌宠、QQ、B 站或其他插件的独立记忆。这里故意用固定的 [0.26.0 稳定发行包](https://github.com/OakcoderX/solopup-memory/releases/tag/v0.26.0)，不是教你追最新预览。已有记忆库先[备份](https://github.com/OakcoderX/solopup-memory/blob/v0.26.0/docs/guides/backup.md)，先用空白工作区和测试 profile，不在原来的环境叠装。

- [固定版本要求](https://github.com/OakcoderX/solopup-memory/blob/v0.26.0/docs/guides/quickstart.md)：Node ≥24.9，DSH ≥0.2.1-rc.0 且 <0.3.0。固定版文档的本地验证环境是 macOS；本文没有在 Windows 重新端到端测试。
- 以下是官方项目指南中的 **desktop profile 示例**。前面只开的 Web 版不能默认用 `desktop`；按快速上手换成实际运行的 profile。若终端找不到 `dsh`，先按官方说明完成 CLI 安装；没确认 profile 就先停在第 2 步。

```sh
dsh plugin --profile desktop add solopup-memory@0.26.0 --ignore-scripts
```

重启相同 profile，打开同一测试工作区，让助手实际调用 `memory_status`，核对加载的是 **0.26.0**。之后重新做第 2 步，这一次在写入和替换时查看工具结果；没写入、被拒绝或还待确认时，不当作成功。**记忆写入、找回规则、按规则交付是三件事。** 哪一环失败就记哪一环。

## 给想复现的人

可以留这四项：DSH/插件版本、模型、在哪一步见到问题、虚构片单的实际答案。不用贴真实聊天、私人目录或密钥。想进一步检查时，走[完整换会话自测](https://github.com/OakcoderX/solopup-memory/blob/v0.26.0/docs/guides/dsh-fish-memory.md)。这篇是按公开文档整理的入门练习，不是我刚完成的一轮真实模型安装评测。
