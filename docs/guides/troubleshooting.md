记录 memory_status、插件版本、DSH 与 Node 版本、错误码和当前项目。0.26 接纳上限内的完整用户消息，单条消息最多 8 KiB，并受整次写入或整理的模型预算约束。收到来源过长提示时，可以另发一条完整消息，把适用范围和例外一起写清。市场网络失败按 DSH 官方代理手册检查宿主自身代理。
