# 条件与例外 / Conditions and exceptions

“平时使用中文，但面向海外客户的交付说明使用英文”不能压成没有条件的“只用中文”。

分别询问内部说明与海外客户说明。conditions 需要全部成立，任意 except 命中即构成例外。若解释不准确，反馈原话、预期适用情境和实际回答；不要只反馈一个通过率。

Test both the ordinary case and the exception. Conditions and exceptions must preserve the original meaning; schema checks cannot certify that meaning.
