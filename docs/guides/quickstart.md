# 快速上手 / Quick start

先确认正在使用 DeepSeek Harness（DSH），Node >=24.9，DSH >=0.2.1-rc.0 且 <0.3.0。当前本地验证环境为 macOS。

安装：`dsh plugin --profile desktop add solopup-memory@0.21.0-beta.2 --ignore-scripts`。重启对应 profile，运行 `memory_status`，核对版本。新会话说“记住：本项目使用两空格缩进”，等待实际写入结果；再开新会话询问此约定。

Install the pinned beta, restart the same profile, check memory_status, then test an explicit remember request and recall in a fresh conversation. A tool registration alone does not prove recall.

公开测试版 / Public beta 0.21.0-beta.2.
