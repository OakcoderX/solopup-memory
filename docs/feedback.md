# Share a trial / 提交试用反馈

请使用 [问题选择页](https://github.com/OakcoderX/solopup-memory/issues/new/choose)：安装/写入故障、语义与召回问题、平台观察分别有模板。

最有用的反馈包含：版本和平台、完整的虚构短输入、实际工具状态、全新会话的问题与回答，以及预期差异。不要把真实记忆库作为附件；裁掉路径、账户和其他个人资料。

Positive observations are welcome too, with exact scope. A single successful trial is not a reliability percentage. Independent reviews should disclose versions, scenario selection, failures and any relationship to the project.
