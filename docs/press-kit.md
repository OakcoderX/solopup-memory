# SoloPup Memory 媒体资料 / Press kit

**English.** SoloPup Memory is an MIT-licensed text-memory plugin for DeepSeek Harness. It carries confirmed decisions and exceptions into a resumed project and links each decision to its source. In 0.26, a supported DSH host can prompt one final check of the actual handoff after a file edit.

**中文。** SoloPup Memory 是给 DeepSeek Harness 用的开源文字记忆插件。换会话继续项目时，可以核对已确认的决定、例外、原话和改动。0.26 支持在兼容的 DSH 中编辑文件后做一次交付复核。

两个历史小样里，按现行约定交付的结果依次为关闭插件 **0/2**、0.25.0-beta.2 **1/2**、0.26.0-beta.1 **2/2**。官方 cattrs 单题本地严格分数是 **0/1、0/1、1/1**。中文改稿仍有文件末尾漏项。 [历史得分与复跑](runs/2026-11-18-memory-delivery.md)
