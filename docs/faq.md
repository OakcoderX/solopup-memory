# FAQ / 常见问题

**Does it work in Codex or Claude Code?** This package targets DeepSeek Harness. No integration with those hosts is claimed.

**免费吗？** 插件按 MIT 开源，不收插件许可费；DSH 所配置的模型服务可能计费。本次推广未购买广告或生成服务。

**Is it fully offline?** Local data storage does not imply offline model-assisted capture and review.

**为什么说记住了却找不到？** 先查真实写入状态，再区分项目归属、召回表达和当前会话上下文。待审或拒绝不等于成功。

**Is this a stable release?** No. Read RELEASE.md for bounded evidence and unresolved acceptance work.

**会把所有聊天都记下来吗？** 不会。候选须经审查，自动整理通常每四轮尝试；明确要求记住的持久信息应走当轮正式工具，仍需检查模型是否实际遵循。

**Can I back up Markdown only?** That is not a full backup; sources, histories and the coordinator also matter.

**忘记是否删除所有副本？** 撤回覆盖受管追踪来源与投影，不承诺原始对话、远端历史、外部备份或未知副本全部删除。
