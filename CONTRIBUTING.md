# Contributing / 参与贡献

SoloPup Memory is a public beta for DeepSeek Harness. Help is welcome with reproducible bugs, documentation, platform observations and carefully sourced semantic counterexamples.

先阅读 README、RELEASE 和 SECURITY。报告问题时注明版本、平台、DSH版本、实际工具状态、预期和实际行为。用虚构短消息复现；不要上传真实记忆库、会话、账户信息或备份。

For code changes, explain the observable failure and run the relevant existing checks. Mark real-model runs separately from deterministic tests. Document any service cost before requesting a paid run. Do not report tests you did not run.

Documentation changes should preserve beta wording, scope boundaries and the distinction between a proposed scenario and measured evidence. Translation improvements are welcome; do not label unreviewed text as native-speaker reviewed.

Use a focused pull request. Contributors choose their own identity and make any required declarations themselves. No signature is supplied on their behalf.
